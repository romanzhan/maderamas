# Madera Más — статичная вёрстка магазина

Интернет-магазин растущих детских стульев (Аргентина, es-AR). Сейчас собирается статика
на Vite + Tailwind + Alpine; позже переносится в тему WordPress + WooCommerce.

Правила проекта — в `*.md` в корне, точка входа `CLAUDE.md`. Состояние работы —
`журнал.md`.

Это рабочая папка с правилами. Сам проект живёт в репозитории `romanzhan/maderamas`
и публикуется на dev.maderamas.com.ar; файлы правил туда не уезжают.

## Требования

Node 20.19+ (проверялось на 24). Браузеры — Safari 16.4+ / Chrome 111+.

## Первый запуск с нуля

```
npm install
npm run brand      # значки сайта и OG-баннер из знака бренда (баннер не хранится в git)
npm run images     # нужны исходники в /images-source (у владельца, не в git)
npm run validate   # проверяет данные и создаёт public/catalog.json
npm run dev
```

Без исходников фотографий `npm run images` отработает вхолостую, а сайт покажет
заглушки — это нормально, не ошибка.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | проверяет данные и поднимает dev-сервер |
| `npm run build` | проверка данных → сборка в `dist/` → `sitemap.xml` и `robots.txt` |
| `npm run preview` | показывает собранный `dist/` локально |
| `npm run validate` | проверяет JSON-контракты и пересобирает `public/catalog.json` |
| `npm run images` | конвейер картинок: размеры, WebP, манифест `data/images.json` |
| `npm run icons` | собирает `src/icons/sprite.svg` из выбранных SVG |
| `npm run brand` | рисует значки сайта и OG-баннер из знака бренда (`public/`, `images-source/og/`) |
| `npm run format` | Prettier по всему проекту |

## Что где лежит

```
data/            содержимое сайта: товары, категории, настройки, словарь текстов
images-source/   исходники фотографий (не в git)
public/          статика и результат конвейера картинок
scripts/         служебные скрипты сборки (данные, картинки, иконки, SEO)
src/pages/       страницы — корень сайта: путь файла = адрес страницы
src/blocks/      крупные блоки: макет, шапка, подвал, карточка…
src/components/  мелкие элементы: кнопка, поле, цена…
src/styles/      main.css — единственный входной CSS, в нём же дизайн-токены
src/scripts/     main.js — единственная точка входа JS
src/icons/       выбранные иконки и собранный спрайт
```

## Как устроена сборка

Страницы собираются из блоков на Handlebars: страница вызывает макет `layout`, тексты
приходят из словаря хелпером `{{t "ключ"}}`, данные — из `scripts/data.js` (единая точка
доступа). Испанских строк в разметке нет.

Адрес страницы = её путь внутри `src/pages`: файл `src/pages/_componentes/index.html`
открывается по `/_componentes/` и в dev, и в сборке.
