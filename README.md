# Madera Más

Интернет-магазин растущих детских стульев из дерева. Буэнос-Айрес, Аргентина.
Интерфейс — аргентинский испанский (es-AR).

Сейчас это статичная витрина: Vite + Tailwind + Alpine. Корзина, избранное и черновик
заказа живут в браузере покупателя; оформление заказа доходит до номера заказа, но
никуда не отправляется — приём заказов и оплата придут вместе с переносом в WordPress
и WooCommerce (Mercado Pago).

Превью для приёмки: **https://dev.maderamas.com.ar**

## Требования

Node 20.19 или новее (проверялось на 24). Браузеры: Safari 16.4+, Chrome 111+.

## Первый запуск

```
npm install
npm run dev
```

Готовые фотографии лежат в репозитории (`public/images`), поэтому сайт поднимается
сразу. Исходники съёмки в репозиторий не кладутся — они тяжёлые и живут отдельно.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | проверяет данные и поднимает сервер разработки |
| `npm run build` | проверка данных → генерация страниц → сборка → карта сайта и robots |
| `npm run preview` | посмотреть собранный сайт локально |
| `npm run validate` | проверяет данные и пересобирает `public/catalog.json` |
| `npm run images` | обрабатывает новые фотографии из `images-source/` |
| `npm run icons` | пересобирает спрайт иконок |
| `npm run brand` | значки сайта и баннер для соцсетей из знака бренда |
| `npm run format` | форматирование |

## Как добавить фотографию

1. Положить исходник в `images-source/` (папка не в репозитории, заводится сама).
2. `npm run images` — конвейер сделает нужные размеры и форматы и обновит
   `data/images.json`.
3. Готовые файлы из `public/images` и обновлённый манифест закоммитить.

## Что где лежит

```
data/        товары, категории, отзывы, статьи, FAQ, настройки, словарь es-AR
src/blocks   блоки страниц       src/components  переиспользуемые компоненты
src/pages    страницы            src/scripts     поведение в браузере
src/styles   палитра и шкалы     src/icons       исходники иконок
scripts/     сборка: проверка данных, генерация страниц, картинки, SEO, значки
public/      статика и готовые картинки
```

Тексты интерфейса — только из `data/dictionaries/es.json`; испанских строк в разметке
и скриптах нет. Цвета и размеры — только токены из `src/styles/main.css`.

## Публикация

`main` собирается автоматически и уезжает на GitHub Pages по адресу
**dev.maderamas.com.ar**. Ручной способ — `npm run build` и содержимое `dist/`.

## Состояние

Вёрстка и поведение готовы. Ждут владельца: фотографии (съёмка героя главной,
мастерская, подушки, превью товаров для мессенджеров) и юридические реквизиты
(CUIT, razón social, ссылка на Data Fiscal). Часть цен и дат на карточках сейчас
демонстрационная — заменяется перед запуском.
