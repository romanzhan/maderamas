# Дизайн-система Madera Más

Источник — brand-гайд «Branding system Madera Más» (артефакт Claude,
утверждён заказчиком, ссылка в `CREDENTIALS.local.md`). Значения ниже
вытащены из его исходника напрямую (hex-коды, а не «на глаз» со
скриншота), 2026-08-18. Если гайд обновится — актуализировать этот файл.

Второй источник — референс-сайт `roststul.ru` (структура/паттерны
интерфейса, см. раздел «Референс-сайт» ниже). Оттуда берём общую
структуру и обкатанные паттерны (карусель на первом экране, карточка
товара, промо-плашки), **не** цвета и не код — цвета свои, стек свой.

## Цвет

Два назначения, не смешивать (правило из гайда): **натуральная** —
это сам бренд (лого, сайт, карточки товара); **яркая промо** — только
реклама/акции (бейджи, плашки, баннеры), максимум 1–2 ярких на экран,
никогда на лого/навигацию/карточку товара.

### Натуральная база — бренд

| Название | Hex | Роль |
|---|---|---|
| Кремовый | `#FBF7F0` | самый светлый фон (карточки, поверхности) |
| Песочный | `#F0EBE1` | фон страницы |
| Дуб | `#C69C6D` | светлое дерево, декоративные акценты |
| Орех | `#5E3D28` | тёмное дерево, декоративные акценты |
| Глина | `#B4633F` | **основной акцент** — CTA, ссылки, «más» в лого |
| Тёплый чёрный | `#2A2620` | основной текст, лого, заголовки |

Вспомогательные (встречаются в UI гайда, не в основной таблице, но
использовать можно как тон текста/бордеров той же натуральной палитры):
`#FCFAF5` (поверхность карточки, чуть теплее кремового), `#E7DFD0`
(бордер), `#9A8B75`/`#A8967E` (приглушённый текст/подписи), `#5A4E40`
(вторичный текст), `#6E6355` (мутный текст), `#97482B` (hover ссылки —
затемнённая глина), `#C9BBA4` (пунктирные бордеры), `#DDB6A3`
(`::selection`), `#EBEDE0`/`#4E5738` (зелёно-оливковый бейдж «DE 6 MESES
A 10 AÑOS» — нейтральный инфо-бейдж, не промо), `#E7F5EC`/`#218A4A`
(зелёный пилл «Envío gratis» — тоже нейтральный статус, не промо-цвет).

### Яркая промо — только реклама

| Название | Hex |
|---|---|
| Электрик | `#2F6BFF` |
| Малина | `#E5397D` |
| Жёлтый | `#FFC336` |
| Зелёный | `#34B663` |
| Оранжевый | `#FF6A2C` |

Правило дословно из гайда: *«промо-цвета не заходят на логотип,
навигацию и карточки товара — только бейджи, плашки, баннеры и акции.
Один-два ярких на экран»*. Явно упомянуто как паттерн — «как в OZON и
roststul» (то есть промо-палитра осознанно вдохновлена стилистикой
референс-сайта).

### Синхронизация с кодом

`tailwind.config.js` **не** хардкодит эти hex — читает их из
`theme.json` (`settings.color.palette`), который остаётся источником
истины (см. «Чего делать не надо» в `CLAUDE.md`: хардкод запрещён).
theme.json нужен в любом случае — им пользуется редактор блоков.

## Типографика

- **Onest** — заголовки/display (600–800). Поддерживает кириллицу и
  латиницу (нужно для админки/гайда на русском + сайта на испанском).
- **Golos Text** — основной текст (400–700). Тоже кириллица+латиница.

Обе — на Google Fonts, самохостим (`@wordpress/scripts`/локальные
файлы шрифтов, не внешний CDN-запрос на прод) — так делает большинство
серьёзных WP-магазинов, снимает layout shift и внешнюю зависимость.

## Логотип

Знак — абстрактная «M» из линий распила/волокон дерева. Два варианта
формы (квадрат, круг), каждая — в рамке и без. Основной цвет знака —
только тёплый чёрный (`#2A2620`), **никогда** не перекрашивается в
промо-цвета (явный пример «нельзя» в гайде — знак в `#2F6BFF`).
Вордмарк: `madera` цветом текста + `más` цветом глины (`#B4633F`).
Минимальный размер: 32px на экране / 12мм в печати.

## Структура главной страницы (утверждено, брать за основу 1:1)

Из раздела «04 Применения → Сайт» гайда — это единственный блок,
который заказчик прямо утвердил как структуру сайта (в отличие от
Instagram/Facebook/Mercado Libre мокапов там же — те просто примеры
брендинга на сторонних площадках, не про наш сайт).

1. **Промо-полоса** сверху — фон `#2F6BFF` (промо!), бейдж «ENVÍO
   GRATIS» (жёлтый `#FFC336`), текст «en tu primera compra», справа
   пилл «6 cuotas sin interés».
2. **Шапка** — лого + вордмарк слева; меню `Inicio · Sillas · Ofertas ·
   Nosotros`; справа — поиск + CTA-пилл «Comprar» (глина).
3. **Hero** — 2 колонки, фон — мягкий градиент `#F3EADD → #FCFAF5`.
   Слева: нейтральный инфо-бейдж «DE 6 MESES A 10 AÑOS», H1 «La silla
   que crece con tu hijo», подзаголовок, два CTA (заливка глиной + аутлайн).
   Справа — фото товара, поверх — скидочный кружок-бейдж (промо-розовый).
   **Поверх этого блока — карусель** (несколько слайдов, не статичное
   фото) — отдельное явное требование заказчика поверх гайда, коррелирует
   с hero-слайдером на roststul.ru (см. ниже). Библиотека — Swiper.
4. **Категорийные плитки** — 4 колонки, однотонные цветные карточки
   (используют весь промо-набор: электрик/малина/жёлтый/зелёный) —
   «Sillas evolutivas», «Ofertas de la semana», «Almohadones», «Envío
   gratis».
5. **«Nuestras sillas»** — сетка карточек товара (3 колонки на
   утверждённом макете, реально — по каталогу). Карточка: фото (со
   скидочным бейджем при наличии), название, материал/дерево, цена
   (+ старая цена зачёркнута при скидке), пилл «Envío gratis» (зелёный,
   не промо) + пилл «6 cuotas» (нейтральный).
6. **Промо-баннер** — градиент оранжевый→малиновый, сезонная акция +
   CTA «Ver ofertas».
7. Footer — не детализирован в гайде, собрать по стандартной структуре
   WooCommerce-магазина (меню, контакты, соцсети, платежи/доставка).

Instagram/Facebook/Mercado Libre мокапы в том же разделе — это
шаблоны для соцсетей и оформления витрины на маркетплейсе, **не**
часть сайта. Полезны отдельно (например, оформление магазина на
Mercado Libre тем же стилем), но не для вёрстки.

## Референс-сайт: `roststul.ru` — техническая сводка

Проверено 2026-08-18 (curl + просмотр). **Это не Битрикс** — платформа
**InSales** (расхожая российская SaaS-платформа для интернет-магазинов,
детект по cookie `ins_*`, `cdn.insales-shop.ru` в путях ассетов,
`generator`-метатегу). Так что вытаскивать «архитектуру 1С-Битрикс» не
нужно — но структура/паттерны интерфейса от этого не менее показательны.

**Стек фронтенда сайта-референса** (для сведения — мы не наследуем код,
только паттерны):
- Bootstrap-подобная сетка (`.container`, `.row`), обширная система
  CSS custom properties (`--bg-grey`, `--button-height`,
  `--color-green`, соотношения сторон `--16x9`/`--1x1` и т.д.) —
  то есть токенизированный дизайн, тот же принцип, что мы делаем через
  theme.json/Tailwind.
- Шрифт — Montserrat (Google Fonts).
- **Карусель — Swiper.js** (`js-widget-slider`, `js-products-slider-swiper`,
  `js-reviews-gallery-swiper` — на hero, в товарных слайдерах и в
  галерее отзывов). Прямое подтверждение выбора библиотеки для carousel.
- Иконки — инлайновые SVG прямо в разметке (268 штук на одной
  странице), без внешнего спрайта/шрифта иконок.

**Структура главной (сверху вниз, по факту осмотра)**:
1. Тонкая промо-полоса (реклама приложения).
2. Шапка: лого, «Каталог» (мега-меню), поиск, рейтинг-бейдж, иконки
   мессенджеров, корзина.
3. **Hero-карусель** на всю ширину, несколько слайдов (индикаторы-точки
   снизу), с фото + оверлей-контентом (промо приложения).
4. Лента клиентских UGC-фото (карусель).
5. Сетка товаров: карточка = фото, скидочный бейдж (красный кружок/
   плашка `-20%`), рейтинг звёздами + число отзывов, цена + зачёркнутая
   старая цена, кнопка «В корзину». Среди карточек — широкие промо-тайлы
   («Комплекты детской мебели»).
6. Ряд категорийных тегов/пилюль.
7. Ещё сетка товаров (видно по прокрутке — вариации одной модели по
   цвету).
8. Соцдоказательство: «Свыше 100 000 клиентов» + карусель скриншотов
   переписок/сторис (доверие через переписку с покупателями).
9. Есть live-чат виджет (Jivo) — не наш паттерн, просто к сведению.

**Вывод для нашей вёрстки**: карусель на первом экране — оправданный,
обкатанный паттерн (не самоцель), это подтверждает решение заказчика.
Карточка товара «фото + бейдж скидки + рейтинг + цена/старая цена +
CTA» — стандарт жанра, наша карточка (по гайду Madera Más) уже совпадает
по составу полей, отличается только тем, что рейтинги у нас пока не
нужны (нет отзывов) — добавить будет некуда, если данных нет.

## Стек и библиотеки (решение, не хардкодим руками)

- **Tailwind CSS** — вместо SCSS для стилизации темы (по прямому
  указанию заказчика: качество вёрстки с Tailwind выше). Токены цвета
  берутся из `theme.json`, не дублируются вручную.
- **Swiper** — карусели (hero, галереи товара). Библиотека, не
  самописная реализация.
- **Иконки** — SVG-библиотека (Lucide) статичными файлами, без рантайм-
  генерации новых иконок вручную под каждый случай.
- WordPress 7.0 + WooCommerce — как и было решено (`docs/decisions/`).
  Товары заводятся как настоящие WooCommerce-продукты (не зашиты в
  код), чтобы корзина/оформление заказа работали из коробки.

Пошаговая настройка тулчейна и вёрстка — см. `CONTEXT.md` →
«Следующий этап» и разбивку по задачам там же.
