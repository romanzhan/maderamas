# Плагины

Плагины в git не хранятся. Этот файл — источник правды по тому, что должно быть
установлено, и в какой версии. Локальные версии продублированы в `.wp-env.json`:
меняете здесь — меняйте и там, иначе локалка разъедется с продом.

## Установленные

| Плагин | Слаг | Версия | Зачем |
| --- | --- | --- | --- |
| WooCommerce | `woocommerce` | 10.9.4 | Ядро магазина |
| Mercado Pago payments for WooCommerce | `woocommerce-mercadopago` | 8.9.0 | Приём оплаты (Фаза 4) |

Версия ядра WordPress: **7.0.2**, PHP **8.3**.

## Рассматриваются, но пока не установлены

| Плагин | Фаза | Комментарий |
| --- | --- | --- |
| SEO-плагин (SEOPress free или Rank Math free) | 5 | Обязательно проверить, что не конфликтует с нашим `hreflang` |
| Плагин кэширования | 5 | Только если хостинг не даёт кэш на своём уровне |

## Правила

- **Без подписок.** Платные плагины с ежегодной оплатой не ставим — заказчик
  уходит от них осознанно. Исключения обсуждаются отдельно и фиксируются в ADR.
- **Мультиязычные плагины не ставим.** Перевод реализован своим модулем,
  см. [decisions/0002](decisions/0002-custom-i18n.md). WPML или Polylang, поставленные
  поверх, будут конфликтовать с ним.
- **Обновление версий** — отдельным PR с правкой этого файла и `.wp-env.json`,
  после проверки на локалке.

## Как обновить плагин локально

```bash
# отредактировать версию в .wp-env.json и здесь, затем
npm run env:destroy
npm run env:start
npm run env:setup
```
