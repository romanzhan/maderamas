# 012 — Hero: карусель с самостоятельными слайдами

**Статус:** готово, 2026-08-18.

## Было

Текст (заголовок/бейдж/кнопки) — статичный слева, крутилась только
картинка справа (плейсхолдеры-шашечки). Не совпадало с референсом
(roststul.ru), где каждый слайд — цельное предложение.

## Стало

`patterns/hero.php` полностью переписан: каждый `.swiper-slide` — весь
блок целиком (свой фон-градиент на токенах, бейдж, заголовок, текст,
цена, две кнопки, фото товара), edge-to-edge (`align:"full"`).

**Данные — реальные, не плейсхолдеры.** Три уже загруженных товара
(`wc_get_product()` по ID из `bin/seed-products.php`): Silla Evolutiva
Infantil (флагман), Silla Alta de Comer Evolutiva, Set Mesa + 2 Sillas
Montessori (новая линейка). Из каждого товара берутся: настоящее фото
(`get_image_id()` + `wp_get_attachment_image_url()`), цена
(`get_price_html()` — так подхватывается «Desde …» для variable-товаров
и локальное форматирование ARS), короткое описание, ссылка на товар.
Бейджи — реальные факты из `docs/content-guide.md` (возрастной диапазон,
5 уровней высоты, «línea nueva»), не выдуманные скидки — старый
плейсхолдер `-20%` не был подтверждённым, убран.

Технические решения:
- Если товар с указанным ID вдруг удалят — слайд просто не рендерится
  (`array_filter`), а не фатальная ошибка; если удалят все — весь
  паттерн возвращает `return;` до вывода разметки.
- Функция сборки слайда — **closure в переменной, не именованная
  функция**: файлы паттернов может `require`-ить не один раз за запрос
  (явная регистрация + собственное сканирование редактора блоков),
  именованная `function` дала бы fatal «cannot redeclare» при повторном
  подключении.
- Один настоящий `<h1>` на странице (первый слайд) — у остальных
  слайдов визуально идентичный `<p role="heading" aria-level="1">`,
  чтобы не плодить второй-третий `<h1>` (SEO/доступность), но сохранить
  визуальную идентичность между слайдами.
- `fetchpriority="high"` на фото первого слайда (LCP), `loading="lazy"`
  на остальных.

CSS/JS carousels не трогали — тот же `.js-swiper`/`carousels.js` из
задачи 003, слайды просто стали полнее по содержимому.
