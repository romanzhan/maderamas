# 006 — Страница товара (single product)

**Статус:** готово, 2026-08-18. Проверено локально (`curl`, товар с
вариациями по цвету) и на staging (визуально).

## Что сделано

- `templates/single-product.html` — за основу взят блокированный
  дефолтный шаблон WooCommerce, переоформлен под нашу дизайн-систему.
- 2 колонки на `md+` (Tailwind grid, как в hero): галерея товара слева,
  справа — заголовок, цена, краткое описание, форма «В корзину»
  (`woocommerce/add-to-cart-form` — сама тянет селектор вариаций для
  товаров с `pa_color`, ничего вручную не собирали), метаданные (SKU,
  категория).
- Ниже — вкладки с полным описанием (`woocommerce/product-details`,
  стиль `is-style-minimal`) и блок похожих товаров (стандартный паттерн
  WooCommerce `woocommerce-blocks/related-products` — не кастомизировали
  под свою карточку, это отдельная небольшая задача при желании).
- Кнопка «Agregar al carrito» — работает: у неё уже класс
  `wp-element-button`, дизайн (пилюля, цвет глины) подхватился из
  `theme.json` сам, без дополнительного CSS.

## Побочная находка (не баг кода — локальное окружение)

Кнопка сначала показывала английский текст «Add to cart» — на staging
всё было по-испански сразу (там уже стоят языковые пакеты `es_AR` для
ядра и WooCommerce, поставлены раньше). Локально в `wp-env` их не было
(свежая установка) — поставил `wp language core install es_AR --activate`
и `wp language plugin install woocommerce es_AR` для консистентности
дальнейшей локальной разработки. Не влияет на деплой — языковые пакеты
не версионируются (как ядро и плагины), это разовая настройка окружения.
