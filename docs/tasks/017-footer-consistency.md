# 017 — Footer и финальная сверка консистентности

**Статус:** готово, 2026-08-18. Последняя задача перестройки дизайн-системы
(010–017).

## Что сделано

- `parts/footer.html`: все текстовые ссылки (Tienda/Contacto/WhatsApp/
  email) были полностью статичными — `text-contrast no-underline` без
  единого интерактивного состояния. Добавлено
  `transition-colors duration-base hover:text-primary` на все.
  Логотип-ссылка в шапке футера — оставлен без цветового hover
  осознанно (это бренд-марка, не навигационная ссылка; клик и
  focus-visible всё равно работают через общее правило в `style.css`).
- `patterns/product-highlights.php`: ссылка «Ver todas →» — та же
  правка (была `text-primary` без hover).
- Обход всех паттернов/шаблонов на предмет ссылок без hover
  (`grep` по `text-*-color no-underline` без соседнего `hover:`) — эти
  два места были единственными; остальные ссылки либо используют
  токен `link` из `theme.json` (уже даёт `:hover` глобально), либо уже
  получили состояния в задачах 010–015 (кнопки/иконки/карточки).
