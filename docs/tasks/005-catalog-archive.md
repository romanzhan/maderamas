# 005 — Страница каталога (архив товаров)

**Статус:** готово, 2026-08-18. Проверено локально (структурно, `curl`)
и на staging (визуально).

## Что сделано

- `templates/archive-product.html` — шаблон архива WooCommerce (страница
  «Shop» и категории). За основу взят блокированный дефолтный шаблон
  WooCommerce (`plugins/woocommerce/templates/templates/blockified/
  archive-product.html`), переоформлен под нашу дизайн-систему (Tailwind,
  та же карточка товара, что и в `patterns/product-highlights.php`).
- Хлебные крошки, заголовок архива, счётчик товаров + сортировка,
  сетка `woocommerce/product-collection` с `"inherit":true` (значит
  автоматически уважает URL — категория/поиск/сортировку/пагинацию,
  без ручной настройки под каждый случай), пагинация, состояние
  «нет товаров».

## Техническая находка: шаблоны (в отличие от паттернов) НЕ подвержены
## багу с кэшем листинга директории

В отличие от `patterns/*.php` (см. задачу 004), новый файл
`templates/archive-product.html` заработал **сразу**, без танцев с
регистрацией. Причина: обнаружение шаблона при рендере страницы идёт
через точечный `file_exists()` по вычисленному пути (WordPress
проверяет конкретное имя файла — `archive-product.html` — а не
сканирует директорию `templates/` целиком), а `file_exists()` не
подвержен обнаруженному ранее кэшу листинга директории — тот бьёт
только по `scandir()`. Так что для **шаблонов** воркэраунд из задачи 004
не нужен; актуален только для **паттернов** (`patterns/*.php`, которые
WordPress ищет через `WP_Theme::get_block_patterns()` → `scandir()`).
