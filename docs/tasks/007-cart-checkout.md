# 007 — Корзина и оформление заказа

**Статус:** готово, 2026-08-18.

## Что оказалось нужно (меньше, чем ожидалось)

Страницы «Cart» и «Checkout» WooCommerce создаёт сама при установке
плагина, **уже с современными блоками** `woocommerce/cart` и
`woocommerce/checkout` (не устаревшие шорткоды `[woocommerce_cart]`).
Это контент страниц, не файл темы — рендерятся через наш обычный
`templates/page.html` (шапка/футер + заголовок + контент), и большая
часть визуала (кнопки, шрифты, цвета) уже подхватывается из
`theme.json` сама — без единой строчки кода с нашей стороны.

Проверено: корзина показывает реальные товары, суммы, форму купона,
переход к оформлению; чекаут — стандартные поля адреса/оплаты
(Mercado Pago уже подключён плагином `woocommerce-mercadopago`, не
трогали).

## Найденный и исправленный баг: часть текста на странице корзины
## была захардкожена по-английски

WooCommerce при автосоздании страницы «Cart» вставляет в её контент
(не в шаблон — в сам `post_content` страницы) готовый паттерн с тремя
статичными текстовыми блоками, которые почему-то **не локализуются
автоматически** даже при активной локали `es_AR` и установленном
языковом пакете (это не динамические строки из PHP/JS-перевода, а
буквальный текст, вставленный в контент при создании страницы):

- «You may be interested in…» → «Podría interesarte…»
- «Your cart is currently empty!» → «¡Tu carrito está vacío!»
- «New in store» → «Novedades»

Страница «Checkout» такой проблемы не имеет — там все блоки
динамические, без захардкоженного текста.

**Исправлено содержимым страницы** (не кодом — это контент, не версионируется
в git, см. `CLAUDE.md`): подменил 3 строки напрямую через `wp_update_post`
на staging и локально. Если когда-нибудь понадобится пересоздать
страницу «Cart» с нуля (например, через WooCommerce → Status → Tools →
Create pages) — учтите, что нужно будет повторить эту правку, дефолтный
паттерн WooCommerce всегда вставляет английский текст независимо от
локали сайта.
