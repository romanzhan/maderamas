# 014 — Каталог: сортировка и пагинация

**Статус:** готово, 2026-08-18.

## Что сделано

- `woocommerce/catalog-sorting` (select «Orden predeterminado» и т.п.):
  разметку `<select>` рендерит блок Woo, `className` блока попадает
  только на обёртку — поэтому стилизован напрямую по реальному классу
  `.wc-block-catalog-sorting select.orderby` (тот же визуальный язык,
  что у `.select` из задачи 010: рамка/радиус/фон/фокус на токенах).
  Шеврон — не картинка плагина форм и не второй SVG-файл: CSS `mask`
  на `::after` со ссылкой на тот же `assets/icons/chevron-down.svg`
  (один файл-источник, просто без прохода через PHP-хелпер — блок не
  даёт вставить туда произвольную разметку).
- `core/query-pagination` (числа/стрелки страниц внутри
  `woocommerce/product-collection`): `.page-numbers` — круглые кнопки
  44×44px, активная — заливка `primary`, hover/focus-visible на
  токенах. **Не проверено визуально** — в каталоге сейчас 10 товаров
  при `perPage:12`, пагинация физически не рендерится (последний срез
  задачи 013 её тоже не показал бы). Стили лежат заранее и сработают,
  как только товаров станет больше 12.
- `woocommerce/product-results-count` («Mostrando N resultados») —
  цвет приведён к `contrast-2` (та же вторичная иерархия текста, что
  и в остальной теме) вместо цвета по умолчанию.
- **Фильтров на сайте сейчас нет** (проверено — в `archive-product.html`
  их не было и раньше, только breadcrumbs/заголовок/сортировка/сетка) —
  пожелание «если у нас есть фильтры, тоже проработать» неприменимо,
  фиксирую явно, чтобы не потерялось.
