# Настройки сайта — что каждая означает

Человеческое описание файла `site.config.json` (`данные.md` §7). Здесь — смысл настроек;
сами значения живут в JSON, менять их нужно там. Файл читается на сборке: после правки
достаточно перезапустить сайт.

Правило: всё, что можно включить или выключить, — это флаг. Выключенный флаг убирает
функцию целиком, не оставляя пустых мест в интерфейсе.

## features — что на сайте включено

| Настройка | Что делает, когда включена |
|---|---|
| `cuotas` | под каждой ценой появляется строка про оплату в рассрочку |
| `secondCurrency` | рядом с ценой в песо показывается справочная цена в долларах |
| `secondLanguage` | появляется переключатель языка интерфейса (товары и статьи остаются на испанском) |
| `blog` | появляется раздел «Blog», статьи и врезка блога на главной |
| `wishlist` | появляются сердечки «в избранное» и страница избранного |
| `promoCodes` | в корзине появляется поле для кода на скидку |
| `reviews` | появляются отзывы покупателей и форма отзыва |

## Остальные настройки

| Настройка | Что означает |
|---|---|
| `cuotas.count` / `cuotas.interestFree` | на сколько платежей делится цена и без процентов ли они. Работает только при включённом флаге `cuotas` |
| `currencies.base` | валюта, в которой заданы все цены в данных и в которой покупатель платит. Для Аргентины — песо (`ARS`), менять её нельзя без пересчёта всех цен |
| `currencies.second` | какая валюта показывается справочной второй ценой (`USD`). Работает только при включённом флаге `secondCurrency` |
| `currencies.rate` | курс доллара для справочной цены. Ставится вручную; пока пустой, вторая валюта не показывается |
| `languages.base` | основной язык интерфейса — испанский (`es`) |
| `languages.second` | второй язык переключателя (`en`). Работает только при включённом флаге `secondLanguage` и меняет лишь подписи интерфейса: товары и статьи остаются на испанском |
| `cart.maxQtyPerItem` | сколько штук одного товара можно положить в корзину за раз |
| `catalog.newBadgeDays` | сколько дней товар считается новым и носит бейдж «Nuevo». Считается от даты, записанной у товара |
| `announcement` | промо-полоса в самом верху сайта. `text` — объявление, `url` — куда оно ведёт (пусто — просто текст), `icon` — иконка слева от текста по имени файла из `src/icons/source` (пусто — без иконки), `enabled: false` — полосы нет совсем. Покупатель может закрыть полосу крестиком, и она к нему не вернётся, пока вы не поменяете `text`. Юридической ссылки в полосе нет с 27.08.2026 — она в подвале |
| `promo` | баннер акции на главной: заголовок, текст, картинка, ссылка. `enabled: false` — баннера нет |
| `contacts` | WhatsApp, телефон, email, Instagram, адрес и часы работы. Из этого собираются подвал, кнопка WhatsApp и страница контактов. Пустой адрес — блок «где нас найти» просто не появляется |
| `shipping.cost` | стоимость доставки в песо, одна на всю Аргентину (решение владельца 26.08.2026: ставка фиксированная, от суммы заказа не зависит). **0 = доставка бесплатная**: на товарах появляется бейдж «Envío gratis», в корзине строка доставки показывает «бесплатно». Число больше нуля — платная: сумма показывается в корзине и чекауте |
| `seo.siteUrl` | адрес сайта. От него строятся карта сайта и превью ссылок в WhatsApp |
| `seo.defaultOgImage` | картинка, которая показывается при отправке ссылки на сайт в мессенджер, если у страницы нет своей |
| `seo.homeTitle` / `seo.homeDescription` | заголовок и описание главной страницы в результатах поиска |
| `legal.cuit`, `legal.razonSocial`, `legal.dataFiscalUrl` | CUIT, официальное название компании и ссылка на страницу Data Fiscal. Обязательны по аргентинскому закону, показываются в подвале |
| `legal.ivaRate` | ставка налога в процентах (сейчас 21). Из неё считается обязательная строка «PRECIO SIN IMPUESTOS NACIONALES» рядом с ценой — закон требует показывать сумму без национальных налогов. Меняется ставка — пересчитается везде само |

## Чего здесь нет

Цены, названия и описания товаров — в `products.json`. Тексты интерфейса (кнопки,
сообщения, подписи) — в `dictionaries/es.json`. Тексты информационных страниц —
в `pages.json`.
